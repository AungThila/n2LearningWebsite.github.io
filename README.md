# 🌸 Sakura N2 Myanmar - JLPT N2 လေ့လာရေးဝက်ဘ်ဆိုက်

ဂျပန်စာ **JLPT N2** အောင်မြင်ရေးအတွက် မြန်မာဘာသာဖြင့် အသေးစိတ် ရှင်းလင်းပြုစုထားသော Interactive Web Application ဖြစ်ပါသည်။

## ✨ ပါဝင်သော အဓိက ကဏ္ဍများ (Features)
- **📖 ဝေါဟာရ (語彙 - 600 Words)**: စီးပွားရေး၊ နေ့စဉ်ဘဝ၊ စိတ္တဇသဘောတရားနှင့် စိတ်ခံစားမှုဆိုင်ရာ N2 ဝေါဟာရ ၆၀၀ လုံး (3D Flashcard မုဒ်နှင့် အသံထွက်စနစ် ပါဝင်သည်)။
- **✍️ သဒ္ဒါ (文法 - 200 Patterns)**: ဆက်စပ်ပုံသေနည်း (接続)၊ အသုံးအနှုန်း ကွဲပြားချက်များနှင့် စံပြဝါကျများ။
- **⛩️ ခန်းဂျီး (漢字 - 370 Kanji)**: ဆွဲချက်အစဉ် သရုပ်ပြကွက် (書き順 Animation) နှင့် ကိုယ်တိုင်ရေးကျင့်ရန် Handwriting Practice Pad။
- **📑 စာဖတ်လေ့ကျင့်ခန်း (読解 - 問題10〜問題14)**: 短文 (5 ပုဒ်)၊ 中文 (3 ပုဒ်)၊ 統合理解 A/B နှိုင်းယှဉ်ချက် (2 ပုဒ်)၊ 主張理解・長文 (2 ပုဒ်) နှင့် 情報検索 (2 ပုဒ်) — စုစုပေါင်း စာပိုဒ် ၁၄ ပုဒ်နှင့် မေးခွန်း ၂၆ ပုဒ်။
- **📜 မေးခွန်းဟောင်း ၁၀ နှစ်စာ (過去問 2016–2025)**: ၂၀၁၆ မှ ၂၀၂၅ အထိ (7月 နှင့် 12月) စာမေးပွဲပုံစံ မေးခွန်းဟောင်းများနှင့် မြန်မာလို အဖြေရှင်းလင်းချက်များ။
